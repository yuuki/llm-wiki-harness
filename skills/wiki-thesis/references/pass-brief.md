# 5 つの角度と subagent ブリーフ

`wiki-thesis` skill の従属資料。角度の定義(§1)と、候補ページが 9 枚以上のときに角度ごとへ投入する Explore subagent のブリーフ雛形(§2)を置く。SKILL.md はここに書いた規則を書き写さない。

## 1. 角度の定義

5 つの角度は、同じ候補ページ群を別の問いで読むためのものである。角度ごとに別のページを読むのではない。

### 支持

命題の**予測**(フェーズ 0 で書いたもの)に一致する記述を探す。見つけたら次を控える。

- 記述の要約。数値なら評価条件(規模、版、ワークロード、データ出自)を添える。
- その source が自ら測ったのか(直接)、主張しているだけか(間接)、他文献を引いているだけか(伝聞)。
- 命題の範囲(規模・条件)と記述の範囲が一致するか。ずれていれば「隣接」へ回す。

### 反対

命題の**反証条件**に当たる記述、または予測と食い違う記述を探す。

- 既存の `> [!contradiction]` callout に命題の主語が出ていれば、その両側のページを読む(`contradiction-index.py --query`)。
- 「X は Y ではない」という否定文だけでなく、「X でも Y にならなかった」という実測の不一致を探す。実測の不一致は否定文より強い。
- 反対する記述が無かったときは、探索語を控える。探していないことと見つからなかったことを区別するため。

### 機序

なぜ命題が成り立つ(または成り立たない)かの**説明**を探す。

- 支持と反対の双方に直接の根拠があるとき、両者を分ける**条件変数**(規模の閾値、版の違い、ワークロードの型)を探す。見つかれば partially の根拠になる。
- 説明が source に無ければ「wiki のソースからは確認できない」。自分で機序を考案しない。

### メタ

根拠の**質**を問う。

- 評価条件が揃っているか。異なる設定の数値を比べていないか。
- 支持する source が同一の著者グループに偏っていないか。利害(自社製品の評価など)は無いか。
- 伝聞の連鎖になっていないか。原典が wiki にあれば原典へ差し替える。
- source ページが lint 由来の stub(本文が短い)なら、根拠として数えない。

### 隣接

拾った根拠が**別の命題**のものではないかを問う。

- 強い版(「常に」「どの規模でも」)、弱い版(「特定の条件で」)、逆向き(主語と述語の入れ替え)。
- 命題の範囲を狭めれば根拠が揃う場合、狭めた命題の形を書く。partially の判定文になる。
- 隣接命題の根拠は本命題の根拠表に入れない。備考として残す。

## 2. subagent ブリーフの雛形

角度ごとに 1 体。同じ候補ページ群を渡す。ファイルは書かせない。

```
あなたは wiki-thesis の「<角度>」担当である。次の命題について、渡されたページだけを読み、<角度>の問いに答える。

命題(逐語): <thesis>
変数: <主語 / 述語 / 範囲>
予測: <命題が真なら書かれているはずのこと>
反証条件: <命題を崩す記述の形>

読むページ(vault 相対パス):
- wiki/sources/@....md
- wiki/concepts/....md
- ...

読み方:
- 各ページは `python3 scripts/wiki-excerpt.py <path> --tail 15 --budget-tokens 1800` で抜粋する。抜粋で足りないときだけ `--section "<節名>"` で広げる。全文 Read はしない。
- (メイン文脈向け)読むページが 6 件を超えるときは、`python3 scripts/wiki-context-pack.py "<命題>" --no-retrieve --pages <ページ...> --budget-tokens 8000 --out /tmp/pack.md` で抜粋の束を 1 ファイルに作り、「読むページ」の代わりにその束を渡してよい。束の末尾の「省略」に挙がったページだけを subagent が個別に抜粋する。
- wiki/index.md、_index.md、wiki/log.md、wiki/hot.md は読まない。
- 担当ページに書かれていないことは推測せず「記載なし」と明記する。訓練データで穴を埋めない。

<角度>の問い:
<§1 の該当角度の箇条書きをここに貼る>

返すもの(テキストのみ。ファイルは書かない):
1. 根拠表の行。1 件ごとに
   | <角度> | 根拠の要約(数値は評価条件つき) | [[@source]] §節 | 直接/間接/伝聞 | 備考 |
2. 「記載なし」だったページの一覧と、そのページで何を探したか。
3. 隣接命題に見えた記述があれば、どの命題の根拠かを 1 行で。
```

角度が「反対」のときは、ブリーフの末尾に次を足す。

```
反対する記述が 1 件も無かった場合は、その旨と、各ページで探した語(否定文、実測の不一致、条件つきの例外)を列挙する。
```

## 3. 返答の取り込み

- 5 体の返答を根拠表に統合する。同じ source の同じ節を複数の角度が挙げたら 1 行にし、側を併記する。
- 「記載なし」の一覧は本文に載せない。log の Gap に、読んだページ数と記載なしの数を書く。
- 隣接命題として返った記述は「命題の分解」の隣接命題に追記し、根拠表からは外す。
